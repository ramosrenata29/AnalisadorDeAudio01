# Analisador de áudio

## Contexto 
Crie uma **Aplicação SPA**  para analisar espectro de um arquivo Mp3.

## Requisitos 

 1. O usuário seleciona um arquivo do seu dispositivo.
 2. Executa um ''play''
 3. O analisador inicia a renderização dos gráficos. 

## Recursos Adicionais 

 1. Permita alterar a frequência de Hz da música que estiver em execução para as outras frequências populares de terapia alternativa.
 2. Permita salvar o arquivo com a nova frequência adicionada. 

## Stack 
* Html, CSS e JS puro (Vanilla)
* Utilize bibliotecas populares para reduzir códigos, erros e manutenção. 
* Vou hospedar no Git Pages.

## UI/UX
* Mobile First,
* Interfaces minimalistas e limpas,
* Efeitos em botões e outros componentes,
* Botão para alternar modo noturno,
* Abas para diferenciar as analises de áudio de acordo com o Hz,
* Cores aos gráficos de acordo com a frequência,
* Cores para frequência de Hz,
* Botão para ajuste de cores para daltônicos.

## Instruções para Agentes de IA

 1. Analise sempre a viabilidade do desenvolvimento.
 2. Não havendo viabilidade, não execute a tarefa e solicite interação humana.
 3. Todo ajuste, correção, incrementação, registre em um arquivo de backlog. Salve o arquivo em /spec/backlog.md registrando a data, a hora e a tarefa executada.
